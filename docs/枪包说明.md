# rifle3 TaCZ 枪包 — 安装与验收

交付物：`out/Rifle3_GunPack_1.0.0.zip`（1208923 字节，51 个文件）

包里有**两个命名空间**：枪本身在 `rifle3:`，弹在 `7x46:`（见第二节）。
TaCZ 会把 zip 里每个 `gunpack_info.json` 各当成一个枪包列出来，所以枪包列表里会
看到 「Rifle3」 和 「7x46」 两行——这是正常的，两行都来自同一个 zip。

模型：全长 **704 mm**、54 件网格、14 个材质；枪里同时带着**标准弹匣**与**四排双进加长弹匣**
两套几何（`mag_standard` / `mag_extended_1` 两根骨骼，装扩容弹匣时引擎隐藏前者）；
枪口是**多槽加长消焰器**（−14 mm 起算，带 3 个矩形侧排气孔与环槽）。

## 一、这个包需要 TML

模型是 **poly_mesh**（111506 个三角面，零精度损失），基础 TaCZ 1.1.8 **不认**这个格式——
它只由 **TML（Tacz Mesh Loader）** 提供。配件同样走 poly_mesh（TML 有
`TaczPolyMeshAttachmentModel`），所以配件也不需要退回方块。

| 实例 | 有 TML？ | 能不能用 |
|---|---|---|
| `1.20.1-Forge_47.4.10` | 有（`tacz-mesh-loader-forge-1.20.1-0.1.8.jar`） | **能**，包已经拷进去了 |
| `DeceasedCraft_CB` | 没有 | 不能，除非把 TML jar 也放进它的 `mods/` |

装法：把 zip 丢进 `<实例>\tacz\` 目录，重进游戏（或 `/tacz reload`）。
同名 id 只能有一份，换包必须重启游戏。

## 二、进游戏怎么找枪

TaCZ 的枪不是原版物品，用**创造模式物品栏里的 TaCZ 页签**找 **R3 Carbine / R3 卡宾枪**；
或者在枪械工作台里合成。

四个配件也在 TaCZ 页签里：**R3 加长消焰器 / R3 1-4 倍瞄准镜 / R3 镂空枪托 /
R3 四排扩容弹匣**。

### 弹药：架空的 7×46 mm

枪**不吃 5.56 了**，改吃这把枪专用的架空口径 **7×46 mm**（`7x46:7x46`，物品名
「§e7x46mm 步枪子弹」/「7×46 实验弹」）。它是随包一起进来的整套独立弹药：

| 项 | 值 |
|---|---|
| 弹匣容量 | 30 发（扩容 60 / 75 / 90） |
| 堆叠 | 60 |
| 排序 | sort 25（排在 24 个原版口径之后，不插队） |
| 弹道色 | `#FFB347` 琥珀色曳光 |
| 合成 | 枪械工作台：铜锭 ×15 + 火药 ×4 + 青金石 ×4 → 40 发 |

弹壳长 46 mm，夹在 7.62×39 与 7.62×51 之间，按包作者给的「缎带色语义」取琥珀
（`#F5BF15` = 中间威力步枪弹，与 5.45×39 / 5.56×45 / 7.62×39 同族）。几何是 5 发
并排的 52 个 cube；抛出的空壳沿 +Z 躺、每面纯色（翻滚时不会亮面朝下）。

它和枪处在**同一个 zip 的两个命名空间**里（`7x46:` 与 `rifle3:`）——TaCZ 的枪包
加载器把整个 zip 当资源根挂载，并对**所有**命名空间做目录扫描，所以这样可行；
CUST GunsmithPack、helldivers、MS-Mobius 等已装枪包实测都这么干。

## 三、验收清单（照着看）

1. **枪能拿出来、外观正常** —— 不是一坨黑块、不是纸片、不是横躺的。
2. **第一人称手的位置** —— 右手在握把上、左手在护木下（这两只手是 TaCZ 用原版玩家手臂画的，
   我们提供的是 `righthand_pos` / `lefthand_pos` 两根骨骼的位置 + 动画里的握姿旋转）。
3. **按 R 换弹** —— 弹匣沿 15.6° 斜轴下坠、消失、新匣上行入井；过程中枪身**向右倾**
   （枪口上抬、略向左偏航），弹匣从屏幕左侧取出，与官方 m4a1 同向。
   左手会离开护木、跟到弹匣上陪着它一起走（`lefthand` 的 position 通道叠了弹匣的位移），
   换完再回护木——不是「原力换弹」。
4. **空仓换弹** —— 换完会拉一下枪机（`bolt` 骨骼前移再归位）。
5. **抛壳口是真开孔** —— 机匣右侧（+X）有一个 70×18 mm 的窗口，透过它能看到**浅灰色枪机**；
   开火后坐和拉机柄时能看到枪机在窗口里前后移动。窗口下沿还能看到枪机槽底。
6. **开火** —— 抛壳从右侧（+X）飞出、扳机有扣动、快慢机可拨到 SAFE。
7. **开镜** —— 装 `scope_std` 后开镜：视野是**一整圈细黑边 + 十字分划**，
   黑边只有发丝宽（镜筒后罩半径 1.143，通光孔 1.02，比值 1.12，与官方镜的
   1.01–1.13 同档），中心画面约占屏幕宽度 61%。拆掉镜用 `iron_view` 机瞄。
8. **配件** —— 把枪口/瞄具/枪托拆下来，枪上会露出 `muzzle_pos` / `scope_pos` /
   `stock_pos` 位置（空位，没有几何）；装回去**外观必须与默认状态完全一致**，
   因为配件几何就是默认件按挂载点原点平移出来的同一份顶点。扩容弹匣装上后
   弹匣变长变宽，弹容量 60/75/90（等级 1/2/3）。
9. **官方配件** —— 在配件界面里应当能直接装官方包的瞄具、枪托、握把、激光、
   枪口和扩容弹匣（见第六节）。
10. **弹药变成 7×46 了** —— 枪不再吃官方的 5.56。创造页签里找「7×46 实验弹」
    （英文 §e7x46mm Bullet），HUD 弹药数 30 发，扩容弹匣下 60/75/90；
    枪械工作台里能用铜锭 15 + 火药 4 + 青金石 4 合成 40 发。空壳抛出来是琥珀色曳光、
    壳身镀镍（不是黄铜色）。如果还在吃 5.56，说明游戏没重启或装的是旧 zip。

### 骨骼（45 根）

- **枪体**：`root → gun`（`gun` 上 24608 个三角面，枪口/瞄具/枪托已移出）
- **弹匣**：`gun → magazine → mag_standard`(13620) / `mag_extended_1`(13798)
- **手臂**：`gun → righthand → righthand_pos`、`gun → lefthand → lefthand_pos`（无几何，只提供变换）
- **可动件**：`bolt`(208) / `charge_handle`(156) / `bolt_catch`(156) /
  `trigger`(2472) / `selector`(1480) / `mag_release`(460)，都挂在 `gun` 下
- **配件挂载点**：`muzzle_pos → muzzle_default`(6624)、`scope_pos → sight`(17294)、
  `stock_pos → stock_default`(3034)。装了同类配件时引擎自动隐藏对应的 `*_default`
- **官方配件的挂点**：`grip_pos`（护木底面 z −45.5）、`laser_pos`（右侧 M-LOK y −28 → 模型 x +1.47，
  与 m4a1 的 +1.46875 同位）、
  `ar_stock_adapter`（= stock_pos）、`laser_adapter`（= laser_pos）。都是空骨，
  TaCZ 按 `<type>_pos` 找位置、按 display 里的 `adapter` 名字找适配器骨，有名字才装得上
- **锚点**：`muzzle_flash` / `shell` / `constraint`（同样挂在 `gun` 下）
- **视角**：`views` 下 `idle_view` / `iron_view` + 7 个 `refit_*_view`；`positioning` 下 `fixed` /
  `ground` / `thirdperson_hand`

**`refit_*_view` 必须带 rotation**（`[0,90,0]` 系）。配件改装界面（默认 Z 键）里的枪不是用
`idle_view` 摆的：TaCZ 拿 `refit_view`（换成对应类型就是 `refit_muzzle_view` 等）这条骨链算
`getPositioningNodeInverse()`，**朝向完全由这些骨的 rotation 决定**。官方 490 把枪的
`refit_view` 全都是 `[0,90,0]` 或 `[0,89.9,0]`（枪沿屏幕横向摆）。早先这里只有 pivot 没有
rotation，枪就保持第一人称的竖向前后朝向、直接怼到镜头上——「改装界面糊屏」就是这个。
现在的 pivot 是用 `work/refit_solve3.py` 反解的：点哪个按钮，那个部件（枪口/枪托/瞄具/弹匣/
握把/激光）正好落在相机 (0, −0.2, 1.45)、整枪沿屏幕 X 横放，与 m4a1/ak47/hk416d 同构。

注意：`righthand_pos` / `lefthand_pos` 上**不放任何几何**——TaCZ 对这两个名字注册了 functional renderer，
渲染时会把骨骼上的模型丢掉、换成原版玩家手臂（`RenderHelper.renderFirstPersonArm`）。
所以「手」由两部分决定：骨骼链的位置（手落在枪的哪里）+ 动画里 `righthand` / `lefthand` 的旋转
（手掌朝向，取 m4a1 的 AR 握姿）。

### 配件（4 个）

| id | 类型 | 几何 | 数值 |
|---|---|---|---|
| `muzzle_std` | muzzle | 自带 geo（72 mm 加长消焰器） | weight .28，ads +.01，inaccuracy ×.92，recoil pitch ×.92 / yaw ×.84 |
| `scope_std` | scope | 自带 geo | weight .42，ads +.05，aim_inaccuracy ×.72 |
| `stock_std` | stock | 自带 geo | weight .28，ads −.02，recoil pitch ×.88 / yaw ×.9 |
| `mag_ext_1` | extended_mag | 无（几何在枪里） | weight .4，ads +.02，`extended_mag_level: 1` |

`scope_std` 带 `zoom: [4.25]` / `scope: true` / `fov: 35.0` 三个键（官方单档定倍镜就是这个写法），
所以开镜会真的切进镜内视角。镜内的通光孔来自 `ocular` 骨（TaCZ 用它做 stencil），
孔半径 1.02 模型单位、后罩 1.1434，黑边比 1.12 —— 官方 8 个镜量出来是 1.01–1.13。
`extended_mag` 不带 model/texture，靠 `mag_extended_<level>` 骨骼换几何，
所以 `extended_mag_ammo_amount` 里每一项对应一个 level → `[60, 75, 90]`。

### 动画（9 个，Bedrock 1.8.0，30 fps 逐帧烘焙）

`static_idle` / `static_bolt_caught` / `shoot` / `draw` / `put_away` /
`inspect` / `inspect_empty` / `reload_empty`(2.375 s) / `reload_tactical`(2.2 s)

移动、开镜、近战、滑铲这些走 TaCZ 内置的 `rifle_default.animation.json`，包里不用带。

**`shoot` 里没有手部通道，这是故意的。** 状态机把 `shoot` 当**叠加（additive）**动画
跑在枪口跳动轨道上（`runAnimation("shoot", track, true, ...)`），里面的每个值都是
**加到**基础轨道（`static_idle`）上的。手姿在 `static_idle` 里已经写了 96°，
再在 `shoot` 里写一遍就会变成 192°——上一版"一开枪手臂就上下翻飞"就是这个原因。
官方 m4a1 的 `shoot` 也只有 root / 枪机 / 子弹 / 相机 / constraint，没有手。
校验脚本里的 `ADDITIVE = ("shoot",)` 就是防止它再被写回去。

音效全部**引用官方 ogg**（`tacz:m4a1/...`），包里不带音频文件。

## 五、离线自检

```bash
python rifle3/work/validate_pack.py
```

检查 zip 内所有资源路径真实存在、骨骼父子无环、poly_mesh 索引不越界、
动画通道只动真实存在的骨骼、关键帧是裸三元数组、reload 的 feed/cooldown 与动画长度自洽、
贴图尺寸与 geo description 一致；配件那一段还查 index→display→slot/data→tag 全链、
`extended_mag_level` 与枪里 `mag_extended_<n>` 骨骼对得上、配件几何单骨且 pivot 在原点、
离挂载点不到 40 单位（防止忘了把原点挪到挂载点）。

弹药链这一段（`ammo_check()`）查的是：枪 data 的 `ammo` 指向的 `index/ammo` 真实存在、
index→display→geo/texture/slot/shell 每一跳都能在 zip 里解析到、两套几何都有 cube、
`positioning` 在就必有 ground/fixed/thirdperson_hand、两种语言的 lang 都含 `index.name` 键、
配方 `result.id` 与枪的 `ammo` 完全一致且 `result.type == "ammo"`、
`type == tacz:gun_smith_table_crafting`、每条材料有 `item` 或 `tag` 且 count ≥ 1。
当前结果 **0 error / 0 warning**。

另有一项单独跑：**绕序检查**。

```bash
python rifle3/work/check_wind.py
```

TML 开着 `FORCE_FLAT_SHADING`，它会**丢掉我们存的 normals 数组、改用多边形绕序重建面法线**。
所以绕序错的面在 Blender 里看不出问题、进游戏却是黑面。这个脚本对导出的 JSON 逐面用
Newell 法求几何法线、与角点法线均值比符号，当前 **38642 面 0 反、0 退化**。

导出侧为此做了三件事（都在 `r3_export_tacz.py`）：

1. 逐面判定是否反转，不再整块 mesh 一律 `[::-1]`（那是上一代的做法，对本身就反的面会翻错）；
2. 丢掉面积 < 0.01 mm² 的碎面 —— 布尔求解器在消焰器和扳机上留了五千多个，
   它们在任何分辨率下都看不见，却会让绕序判定拿到随机法线；
3. n-gon 改用 Blender 自己的 `calc_loop_triangles()` 三角化，不再从 0 号角点扇形展开
   （扇形展开在凹多边形上是错的，在圆角上会切出细长条）。

### 官方配件兼容

`allow_attachment_types` = scope / stock / muzzle / grip / laser / extended_mag，
`allow_attachments` 里除了本包 4 个 tag，还引用了官方 8 个 tag：

```
#tacz:scope_scope   #tacz:scope_sight   #tacz:muzzle   #tacz:stock
#tacz:grip          #tacz:ar_laser      #tacz:extended_mag   #tacz:ammo_mod_no_he
```

**自带瞄具挂在 `sight` 而不是 `scope_default`。** 这是字节码里读出来的：TaCZ 的
`allAttachmentRender()` 遍历附件类型时明确跳过 `SCOPE`（`type != NONE && type != SCOPE`），
所以 `scope_default` 这个骨**永远不会被隐藏**——它只会和装上的瞄具重叠成两个镜子。
会被 `scopeHiddenRender` 处理的是 `sight`（镜位空时显示）/ `sight_folded`（装了镜时显示）/
`mount`（装了镜且 `show_mount` 时显示）。本枪的自带镜体因此放在 `sight` 上：镜位空时露出来，
一旦装上任何瞄具（包括我们 `builtin_attachments` 里常驻的 `scope_std`）就自动隐藏。
换句话说，两个分支都只会画一个镜子，不会叠。

所以官方包里那 19 个瞄具/红点、9 个枪托、12 个握把、激光、枪口、扩容弹匣和
FMJ/HP 弹种改装，在配件界面里都能直接装到本枪上。它们的几何挂在我们的
`scope_pos` / `stock_pos` / `grip_pos` / `laser_pos` / `muzzle_pos` 上；
官方枪托/激光的 display 里写着 `"adapter": "ar_stock_adapter"` 这类适配器名，
所以枪里也放了同名的空骨，否则那一档配件会被静默忽略。

注意两点：①官方瞄具自带 `scope/zoom/fov`，装上后开镜就是它自己的视野，
与我们的 `scope_std` 不冲突；②官方配件按 m4a1 的挂点位置设计，
装到本枪上位置正确、**外形比例**未必处处协调（本枪比 m4a1 短一截）。

## 六、两个花了时间的坑

**抛壳口被自己的装饰板挡住。** 抛壳口是用布尔从 `Upper` 和 `UR_detail`（那块外凸的
抛壳口装饰板）上切出来的。`Upper` 切得干干净净，但 `UR_detail` 是**几层重叠壳体**
union 成的，EXACT 求解器只切掉了外面那层盖，把内层盖（y=−22.9 / −23.6 / −18.6）
留在了窗口中间——渲染图和游戏里都只看得到一个浅坑，看不到枪机。改成用 bmesh
**直接删掉窗口矩形内的面**（`open_window()`），装订板留着 2–4 mm 的边框，
窗口才是真的通的。判断依据不能看渲染图（两侧渲染逐像素相同就是"完全被挡住"的信号），
要用射线打：`work/verify_port.py` 从 −Y 侧打过去，窗口内应该先打到 `Bolt @ −18.5`
而不是 `UR_detail`。

**配件原点。** TaCZ 的配件几何按"挂载点即原点"存放，最终位置 = 挂载骨 pivot + 局部坐标
（官方 trident 补偿器放到 m4a1 `muzzle_pos` 上正好盖住原厂鸟笼，可以验算）。
所以 `r3_att_geo.py` 把 `*_default` 骨的顶点整体减去挂载骨 pivot，配件里只留一根
`pivot [0,0,0]` 的骨骼；校验脚本里那条"离挂载点不到 40 单位"就是防止忘了做这件事。

## 七、还没验证的

**没在这次改动之后进游戏跑过**（换上「加长消焰器 + 四排大弹匣」这一版模型之后）。 上面所有结论都来自：Blender 内预览
（`work/geo_preview.py`、`work/port_view.py`）、射线自检（`work/verify_port.py`）、
与官方包逐字段比对、以及 TML 的字节码反编译。

真正只有游戏能回答的是：抛壳口这个开孔在手里的实际观感、四件配件的拆装是否正常、
以及装/拆配件时外观是否真的看不出差别。

**7×46 弹这一版也没进过游戏**。能离线确认的是：文件全在、路径全通、
两套几何各有 cube、lang 键齐全、配方指向同一个 `7x46:7x46`、
枪 data 的 `ammo` 已改成 `7x46:7x46`。进游戏要顺带看的：
①创造页签里有没有「7×46 实验弹」这一格；②枪的 HUD 弹药计数是不是 30/60；
③按 R 换弹后弹匣里的子弹模型（如果启用）和枪口曳光是不是琥珀色；
④打出去的弹壳在落地翻滚时有没有出现亮面朝下的诡异反光。

另外要注意：**枪包列表里会多出「7x46」一行**（同一个 zip 的第二个命名空间），
两行都显示是正常的；卸载/换包时按 zip 走，不要以为是重复安装。

**换弹左手 / 改装界面横放这两条也还没进游戏复验**：
左手的通道是数值验证过的（`work/hand_track2.py` 逐步采样：弹匣离手距离在搬运段恒为
0.14–0.7 模型单位，静止段回到 12.35），改装界面七个 `refit_*` 骨的 pivot 是用
`work/refit_verify.py` 按真实 `getPositioningNodeInverse()` 复算的（整枪 x −1.15..1.15、
z 1.34..1.56，与 m4a1 同构）。但「手看起来像真的抓住弹匣」「按 Z 时枪横在身边」这两件事
只有游戏能回答。

**「开枪不再翻飞 / 镜框变细 / 能装官方配件」这三条也还没进游戏复验**：
前两条有离线判据（`shoot` 通道表、`work/scope_sight.py` 渲出的镜内视野图，
通光孔占屏宽 61%、黑边比 1.12），第三条只有「tag 链 + 挂点骨 + 适配器骨都在」
这一层证据，实际装配效果要进游戏看。

**手的位置是推算的，需要一次游戏内定标。** 手骨的 pivot 是这么来的：拿官方 m4a1 的三骨链
（`gun_and_righthand → righthand → righthand_pos`）解出等价的局部 pivot，再整条链滑到
「握把/护木几何中心 + 官方 37/20 把枪的中位偏移」（右 3.3/1.9/15.9、左 2.7/6.6/18.2 模型单位）。
离线复核（`work/handcheck.py`）里两个锚点都精确落在目标上，但官方那 47 把枪的偏移量本身
标准差有 1–4 个单位（≈ 20–75 mm），所以手掌压在握把上的深浅只能进游戏看。
