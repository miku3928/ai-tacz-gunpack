# 7×46mm 步枪弹 · 物品图标设计说明

架空口径 **7×46mm**，按 tacz_default_gun 的视觉语言绘制。产物 32×32 RGBA，可直接放进 `assets/<包名>/textures/ammo/slot/`。

---

## 一、和 5.56 怎么区分

第一版直接复刻了 5.56×45 的骨架，只换缎带文字。问题是缎带同为琥珀色（这是弹种分类色，不能改），骨架也相同，**放进物品栏基本认不出来**。

新版从三个层面拉开距离，按重要性排序：

### 1. 骨架加高 2px —— 弹头更修长

| | 5.56×45 | 7×46 新版 |
|---|---|---|
| 弹尖起始行 | y=3 | **y=1**（高 2px） |
| 弹头段 | y=3–11（9 行） | **y=1–11（11 行）** |
| 弹壳肩部 | y=12–15（4 行） | y=12–15（4 行） |
| 缎带 | y=16–22 | y=16–22 |
| 弹壳下段 | y=23–28（6 行） | **y=23–27（5 行）** |
| 抽壳沟 | y=29 | **y=28** |
| 底缘 | y=30 | **y=29** |
| 总高 | 28 行（y=3–30） | **29 行（y=1–29）** |

弹头占整个图标的上半部分，弹壳下段相对变短 —— 这正是 7mm 细长弹头配 46mm 短壳的视觉特征。**这是最关键的一条**：形状差异在 16px 下也成立，颜色差异在小尺寸会被模糊掉。

逐行宽度（stock → 新版）：`3(w25)` → `1(w25)` 起尖，`6(w29)` → `4(w29)` 到全宽，弹头全宽段从 6 行拉长到 8 行。

### 2. 弹尖涂色标记

原包里没有弹尖涂色的口径，这是新增的视觉语汇，专门用来标示"这是特殊弹"。默认黑弹尖（穿甲标记），也可用绿（战术）/ 红（燃烧）。

### 3. 弹壳换材质

| 变体 | 弹壳 | 弹尖 | 文件 |
|---|---|---|---|
| 默认 | 镀镍（银灰） | 黑 | `7x46.png` |
| 军械 | 绿漆 | 绿 | `7x46_lacquer.png` |
| 特殊 | 蓝钢 | 红 | `7x46_bluesteel.png` |
| 原始 | 黄铜 | 无 | `7x46_brass.png` |

黄铜版是"退回原版"的选项 —— 如果觉得改太多，用这个。

## 二、保留的不变量

这些是原包的硬规范，不能动：

**缎带色 = 弹种分类**。7×46 壳长 46mm，夹在 7.62×39（39mm）和 7.62×51（51mm）之间，属中间威力步枪弹，取琥珀 `#F5BF15`，与 5.45×39 / 5.56×45 / 5.8×42 / 7.62×39 同族。

| 缎带色 | 语义 | 原包口径 |
|---|---|---|
| `#4BA933` 绿 | 手枪弹 | 9mm / .45ACP / .22WMR / 7.62×25 |
| `#F5BF15` 琥珀 | 中间威力步枪弹 | 5.45×39 / 5.56×45 / 5.8×42 / 7.62×39 |
| `#00AAAA` 青 | 全威力步枪弹 | .308 / 6.8×51 / 7.62×54R / 7.92×57 |
| `#C43434` 红 | 马格农 / 大口径 | .30-06 / .338 / .357 / .45-70 / .500 / .50AE / .50BMG |
| `#3239D4` 蓝 | 霰弹 | 12G |
| `#670D95` 紫 | 爆炸物 | 40mm / 20×82 / RPG |

**缎带几何**：7 行高（y=16–22），右端斜切，行 16 到 x=31，之后每行左收 1px，行 22 收在 x=25。这个斜度在 25 张原图里完全一致。

**缎带是贴在弹壳上的**，不是把弹壳挖空 —— 斜边收进去的几格露出弹壳本色。第一版做成透明，逐像素比对时被抓出 15 个像素。

**字模**：用原包 font.png 里的 3px 数字和那个 3×3 的叉号，不是另设字形。

**硬边无抗锯齿**，7 级色阶。

## 六、完整素材（枪包 7x46_GunPack_1.0.0.zip）

图标只是第一层。tacz 的弹药是一个独立注册的 item，除了物品栏贴图还要 3D 模型、UV 图集、抛壳、以及四个注册文件。全部按默认包的目录规范补齐：

```
7x46_GunPack_1.0.0.zip
├─ gunpack.meta.json                    {"namespace": "7x46"}
├─ assets/7x46/
│  ├─ gunpack_info.json                 version / name / desc / license / authors / date
│  ├─ display/ammo/7x46_display.json    model + texture + slot + shell + tracer_color
│  ├─ geo_models/ammo/7x46.json         弹箱 11 bones / 52 cubes
│  ├─ geo_models/shell/7x46_shell.json  抛壳 1 bone / 4 cubes
│  ├─ lang/{en_us,zh_cn}.json           包名 + 弹药名（中文名带 §e 琥珀前缀）
│  └─ textures/
│     ├─ ammo/slot/7x46.png             32×32 物品图标
│     ├─ ammo/uv/7x46{,_n,_s}.png       128×128 UV 图集（声明 64×64）
│     └─ shell/7x46_shell{,_n,_s}.png   64×64 抛壳贴图（声明 16×16）
└─ data/7x46/
   ├─ index/ammo/7x46.json              stack_size 60 / sort 25
   └─ recipes/ammo/7x46.json            铜 15 + 火药 4 + 青金石 4 → 40 发
```

### 3D 弹箱

模型是 `7×7×3.5` 的牛皮纸箱，4 发竖立 + 1 发横躺在箱前，共 52 个 cube。

**Bedrock 几何的两个坑**（踩过才知道）：

1. **bone 的 pivot 只旋转，不平移**。cube 的 origin 是绝对模型空间坐标，pivot 只是旋转中心。想放 4 发子弹不能用 4 个不同 pivot 的 bone —— 会全部叠在原点。正确做法是把每发的基点烘进 cube origin，bone 的 pivot 设成同一个点仅作转轴。
2. **uv 坐标按 texture_width/height 算，不是 png 尺寸**。文件里声明 64×64，png 是 128×128，采样时 uv 除以 64、像素坐标除以 128。写错就是满屏错位。

**箱子尺寸反复改了三次**：先照抄原包 5.56 的 `7×11.5×3.5`，但 UV 拉了 14×18，正立面像素密度和侧面 7px 宽对不上，纸箱纹理被纵向拉伸。改 7×9、7×10 都失败。最终定 `7×7×3.5` + 正立面 `14×14`，每面严格 2 uv / 1 模型单位 —— **宁可箱子矮一点，也要保证每个面的像素密度一致**，这是手绘像素包的核心观感。

**删掉的装饰**：盖子翻页、箱口小标牌 —— 在斜视角会伸出箱体形成"飞片"伪影，全部去掉，箱内只留一块暗色内底板。

### UV 图集（128×128，声明 64×64）

原包所有 UV 图集都是声明尺寸的 2 倍分辨率（556 声明 32→png 64，762x39 声明 64→png 128），所以我们也用 2 倍。**不是 2× 整数放大** —— 原包 2×2 块的均匀率只有 56%~84%，是独立手绘的。

图集内容：三种箱子面（正/背/侧）+ 顶/内/底 + 弹壳的 10 个纵向分段条（壳身、底缘、抽壳沟、肩×2、颈、弹头、蛋形×2、弹尖）+ 底火 + 8 个纯色补丁（给 1~2px 小面用，避免拉伸）。

纸箱正面：牛皮纸底 + 噪点，琥珀标签带（10px 高）里印 `7X46`，下面一条 stencil 横线 + 4 个子弹象形，左下 `60` 计数。最初这里印的是 `STD`，3D 里有 2px 高糊成一片看不出来，换成了图形。

弹壳/弹头用**水平对称的明暗 ramp**（暗→亮→暗）模拟圆柱 —— 4 面盒子经过 ramp 后看起来是圆的。这是原包的做法，照抄。

### `_n` / `_s` 两张附加图

- `_n`：原包全部是纯平的 `(127,127,255)`，alpha 跟主图一致。tacz 只用它的 alpha 剪影，所以直接铺平就行。
- `_s`：**G 通道是金属度，R 通道是粗糙度**。弹壳给 metal 230 / rough 60~70，弹头 200 / 50，纸箱 0 / 215。注意原包有的口径 `_s` 红通道只有 40（表示很光滑），G 却是 230 —— 说明这两个通道确实各管各的。

### 抛壳

抛壳模型 4 个 cube：壳身 + 颈部 + 底缘 + 底火，声明 16×16 的贴图（png 64×64），骨骼名 `7x46`，pivot `[8,0,-8]`。

**这里放弃了原包的 `rotation: [90,0,0]`**。原包让壳身绕 X 转 90° 立起来，但抛壳在飞行中会翻滚，旋转后的面朝向不可预测，明暗关系会翻。我们的做法是让炮弹壳沿 +Z 轴躺着，**每个面用不同的纯色**（上=亮、下=暗、左右=中间调），交给游戏的方向光照去算 —— 这样无论翻到哪个角度都不会出现"亮面朝下"。

### 注册文件

`index/ammo/7x46.json` 只有 4 个字段：`name`（语言键）、`display`（指向 display json）、`stack_size`、`sort`。

**sort 决定在创造模式物品栏里的顺序**，原包 24 个口径占了 1~24，所以我们取 **25**，排在所有原版弹药后面，不插队。

`display` 里的资源路径是 tacz 的 id 语法，展开规则：

| id | 实际文件 |
|---|---|
| `7x46:ammo/uv/7x46` | `assets/7x46/textures/ammo/uv/7x46.png` |
| `7x46:ammo/slot/7x46` | `assets/7x46/textures/ammo/slot/7x46.png` |
| `7x46:ammo/7x46` | `assets/7x46/geo_models/ammo/7x46.json` |
| `7x46:shell/7x46_shell` | geometry **和** texture 同名，两处都要有 |

`tracer_color` 取 `#FFB347`（琥珀偏橙），和缎带色同族但更亮，曳光在暗处能读出来。

### 合成表

照抄原包中间威力步枪弹的结构（5.56 是铜 15 + 火药 3 → 45 发）：

| 材料 | 数量 |
|---|---|
| 铜锭 | 15 |
| 火药 | 4 |
| 青金石 | 4 |
| **产出** | **40 发** |

多要一格火药 + 4 颗青金石（青金石在原包是"穿甲/高价值弹"的语汇，.338 / .50AE 都在用），产出比 5.56 少 5 发 —— 定位是"贵一点、穿甲强一点"。
